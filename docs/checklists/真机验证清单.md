# 真机验证清单（Phase A）

> 依据：AGENTS 规则 12（真机项必须标注）、plan.md §5 验证纪律、Spike 2 结论。
> 状态：**全部未执行**——前置条件见下。执行时逐项填「结果/证据」，不得跳过。
> 真机要求：Android 8+（建议同时覆盖一台国产 ROM：小米/华为/OPPO 任一，验证后台限制）。

## 前置条件

1. **T3**：NIBI 账号中心已注册 NIBI-GO OIDC native app（`nibigo://login`），`EXPO_PUBLIC_NIBI_GO_OIDC_CLIENT_ID` 已配置；
2. **T4**：桌面 Host 审批 capability 开闸（interaction 事件到达手机）；
3. **T5**（E2E 项）：桌面 transport E2E 插桩已合入；
4. dev-client APK（`pnpm --filter @nibi-go/app exec expo run:android` 或发布构建）已安装；
5. 桌面端：已登录同一 NIBI 账号、Web 远程控制开启、屏幕上有二维码。

## A. 登录与配对（A1）

| # | 步骤 | 预期 | 结果/证据 |
|---|---|---|---|
| A1 | 冷启动 App → NIBI-WORK → 登录 NIBI 账号 | 系统浏览器打开 Zitadel 登录页 | |

| A5 | 杀进程后重开 | 免扫重连（持久凭据），无需重新扫码 | |
| A6 | 在另一账号下打开带 sid 的二维码 | 「该设备不属于当前账号」错误（device-not-owned） | |
| A7 | 桌面端删除设备后重连 | 归属失败 → 引导重扫码 | |
