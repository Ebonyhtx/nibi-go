NIBI-GO UI/UX 2.0

纸上鸟 2.0 · 墨夜 2.0 · 动效契约

1.x 的品牌底色是对的（暖奶油纸面 + 墨蓝字 + 橙色点睛），但执行层是拼出来的： 9 个页面各写一套头部、字号从 9 到 15.5 随手挑、圆角 4/9/10/11/12/14 混用、6 个弹层各写一套 Modal、 遮罩透明度四种并存、动效只有零星几处。 2.0 不换品牌，重做执行层：一套 token、一套基础组件、一套动效契约，并第一次真正打开墨夜深色。

01设计原则

一套阶梯，不许即兴

字号只取 6 档（20 / 16 / 15.5 / 14 / 12.5 / 11），行高成对给出；圆角 4 档（8 / 14 / 18 / 999）； 高度走 size（44 / 38 / 32 / 28 / 52）。页面里出现的任何数字都必须能在 token 表里找到出处。

层级靠面，不靠阴影堆

纸面 / 次级面 / 卡片 / 玻璃面四层足够了。投影只给三档：卡片、菜单、浮层； 浅色用暖墨投影、深色换中性黑——同一套参数在两种主题下都成立。

动效是回答，不是装饰

每一次动效都在回答「刚才发生了什么」：按下有回缩、键盘跟手上移、面板从底部进来、 数值变化时环在走。禁止粒子庆祝与常驻流光；系统「减少动态效果」一律直出终态。

沿用与废止（相对 1.x 的对标口径）

  • 沿用 70/25/≤5 的强调色纪律（橙只给主 CTA、发送键、选中态、进度）。
  • 沿用 会话即首页、抽屉装会话、宠物停在输入栏正上方、侧右缘上下文占用环。
  • 沿用 不引入字体、不做纸纹理、深色不用蓝/橙。
  • 废止 「结构照 dsh-Go 一比一」的口径——2.0 起以本文档为准，只保留上面的结构纪律。
  • 废止 各页面自绘头部/按钮/弹层；统一走 ui/ScreenHeader、ui/PillButton、ui/Sheet。

04动效契约

三档时长 + 一组贝塞尔，全应用共用；组件不得自定曲线。系统「减少动态效果」开启时一律直出终态。

fast150ms小件状态切换：按压回缩、勾选反馈、弹窗退出
base220ms常规过渡：键盘跟随、状态横幅展开、消息入场、遮罩淡入
slow320ms大件：底部弹层、抽屉面板、上下文环数值补间
page450ms整页转场（保留给路由层，当前用系统默认）
standard贝塞尔cubic-bezier(.22, 1, .36, 1) —— 快起缓停，默认
enter / exit贝塞尔(.2,0,0,1) 入场的大动程；(.4,0,1,1) 退场不拖泥
spring三档gentle 面板 / snappy 按钮 / bouncy 宠物与大件入场

动效落点

输入与导航

  • 键盘跟随：输入栏随键盘高度补间上移（原来硬跳一下）。
  • 抽屉：320ms 滑入 + 遮罩淡入；内容 8px 视差与分组 stagger（24ms/项，封顶 240ms）。
  • 按压：所有可点元素统一 scale 0.94–0.98 + 弹簧回弹，替代只变透明度。

会话与状态

  • 流式光标：品牌色竖条呼吸（1.1s，opacity 100% → 15%）。
  • 消息入场：新行淡入 + 6px 上移；历史恢复不播（按 rowId 水位判断）。
  • 桌宠状态机：待审批 → 台钟、思考 → 思考云、流式/工具 → 敲码、完成 → 对勾 2.4s、断链 → 红叹号、未就绪 → Zzz。
  • 上下文环：占比变化时弧长在 320ms 内补间（约 20fps 上限，不抢帧）。

05组件与职责

组件替代了什么约束
ui/ScreenHeader9 处各自复制的 root/head/back/title自带安全区内边距；标题单行省略；右槽只放一个动作。
ui/Row · ToggleRow · SectionCard · Divider三套 ToggleRow + 各页 section/card 组合行高 52；图标底 32/14 圆角；分隔线由卡片画。
ui/PillButtonborderRadius 11/12/chip 混用的按钮4 变体（primary/secondary/danger/ghost）× 2 尺寸。
ui/Sheet6 个 Modal animationType="fade"进出场动画自带；退出动画播完才卸载。
ui/MenuRowindex 里 5 处内联菜单行44 行高；28 图标底；右侧勾选/chevron 二选一。
motion/PressableScaleopacity 0.4 按压native driver；支持 ref（测锚点）与函数式 style。
motion/AppearIn · staggerDelay无只在挂载播一次；尊重 reduce-motion。
motion/useKeyboardFollowindex 手动 setState 键盘高度返回 Animated.Value，供 marginBottom 插值。

06验收口径

  • 浅色 / 墨夜各逐屏截图（聊天、抽屉、设置 7 屏、市场、插件中心、Provider、弹层），不靠「门禁全绿」代替肉眼。
  • 切换外观三选后立即生效、无白屏闪烁；重启后保持。
  • 动效与宠物同播时聊天滚动不掉帧（低端机红线：宠物帧循环持续、滚动跟手）。
  • 系统开启「减少动态效果」：所有动效直出终态，功能不受影响。
  • 组件层面：页面文件里不再出现裸 fontSize、字面量 borderRadius、写死的投影色。
